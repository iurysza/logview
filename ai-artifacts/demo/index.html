How it fits

Thin doors, shared core

The UI and the CLI only turn keys or arguments into a query string. Everything after that is shared.

Query language

Words search text. key:value narrows.

level:W tag:Database pid:4321 pkg:com.example.app lock timeout
level:W warning and worse
tag: exact tag
pid: one process
pkg: an app, by UID
other words text, any case

Quotes keep spacing: "a b". Typos stay visible: lvl:W is just text. Repeating a key is an error. Every filter prints back in one canonical form, and parsing that form gives the same filter. More than 3,000 checks cover this.

Filters as you type · x clear · u undo · c copy
  • / opens one query line. Results update while you type. Esc puts the old filter back.
  • x clears all filters. u undoes the last change. ↑ ↓ recall earlier queries.
  • The status line shows matched of total, not just the total.
  • Zero matches says why, instead of showing a blank list.
  • Matching text is highlighted, using the same ranges as the matcher.
  • c copies the query, ready to paste into the CLI.
  • No flicker: no full-screen clear, synchronized output, and identical frames are skipped.
